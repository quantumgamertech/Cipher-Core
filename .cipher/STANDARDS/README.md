# Standards

Standards translate Cipher Core's philosophy into repeatable engineering practice.

- [ENGINEERING.md](ENGINEERING.md) — architecture and delivery principles
- [NAMING.md](NAMING.md) — names, versions, commands, and files
- [CODING.md](CODING.md) — implementation quality and review expectations

Safety rules in [SAFETY.md](../SAFETY.md) take precedence over these standards.

Standards should be enforceable where practical. If a standard repeatedly needs exceptions, revise the architecture or document the exception through a decision record.
