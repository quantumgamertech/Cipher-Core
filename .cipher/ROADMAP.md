# Roadmap

The roadmap expresses durable direction, not a deployment commitment.

## North star

Cipher Core becomes a reliable, provider-independent personal operating system in which Cipher can reason, remember, communicate, and use approved capabilities through safe, direct interfaces.

## Strategic stages

### Foundation

- Maintain the Operating Manual as the canonical engineering reference.
- Formalize subsystem contracts and decision records.
- Keep production protected by lab-first workflows.
- Establish versioned Bridges for important local applications.

### Intelligence

- Introduce provider adapters with consistent inputs, outputs, and observability.
- Add context selection and memory retrieval policies.
- Separate reasoning quality from provider identity.
- Support local and remote providers without architectural forks.

### Capability

- Create a governed Skill registry and lifecycle.
- Add typed capability permissions and approval policies.
- Expand direct Bridges while retiring fragile UI automation.
- Standardize dry-run, validation, and rollback behavior.

### Presence

- Develop Companion as Cipher's coherent visual and voice presence.
- Express state without inventing a second identity.
- Support multiple presentation surfaces through the same Identity Layer.

### Reliability

- Add health checks, structured telemetry, compatibility matrices, and recovery tooling.
- Define documentation ownership and review cadence.
- Validate backups and rollback procedures periodically.

## Non-goals

- Binding Cipher to one AI provider.
- Copying another assistant's identity or conventions.
- Accumulating hidden automation paths.
- Trading production reliability for demonstrations.

## Roadmap governance

Roadmap items become commitments only through an approved implementation plan. Architecture changes require a decision record. Production changes require separate authorization.
