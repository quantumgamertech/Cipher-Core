# Knowledge Memory

Stores verified, reusable technical knowledge that improves future Cipher Core work.

## Appropriate content

- confirmed compatibility facts;
- validated protocols and interfaces;
- repeatable diagnostic findings;
- known failure signatures and causes;
- verified recovery procedures.

## Quality rules

- Cite the source or validation.
- Record version and environment when material.
- Separate observation from conclusion.
- Add a review date for drift-prone facts.
- Prefer links to decision records and subsystem documentation over duplication.
