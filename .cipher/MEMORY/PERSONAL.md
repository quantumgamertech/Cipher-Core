# Personal Memory

Stores durable personal context that is explicitly appropriate and useful to retain.

## Allowed

- preferred form of address;
- stable accessibility requirements;
- durable workflow context;
- explicitly approved personal facts relevant to collaboration.

## Excluded

- credentials and authentication material;
- unnecessary sensitive personal information;
- speculative traits or psychological profiling;
- temporary conversational details without future value.

## Entries

No personal memory entries are defined by this operating-manual revision.
